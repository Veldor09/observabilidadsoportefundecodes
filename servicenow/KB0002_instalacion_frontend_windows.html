Instalación del Frontend Fundecodes Digital en Windows

Este artículo describe el proceso para instalar y ejecutar el frontend del sistema Fundecodes Digital en Windows. El frontend es una aplicación web desarrollada con Next.js 14 y Tailwind CSS. Se conecta al backend NestJS a través de su API REST.

1. Descripción del sistema

El frontend provee la interfaz de usuario para todos los módulos del sistema Fundecodes: panel administrativo, gestión de proyectos, voluntariado, facturación y reportes.

Stack tecnológico:

  • Next.js 14 — Framework React con renderizado del lado del servidor (SSR)
  • Tailwind CSS — Framework de estilos utilitario
  • Node.js 20 — Runtime de JavaScript

2. Requisitos previos

HerramientaVersión mínimaDescarga
Windows 10 / 11 (64-bit) —
Node.js 20.x LTS https://nodejs.org/en/download
Git para Windows 2.x https://git-scm.com/download/win
Nota: El backend (KB0001) debe estar corriendo en http://localhost:4000 antes de iniciar el frontend.

3. Instalar Node.js en Windows

  1. Descargar el instalador LTS desde nodejs.org (archivo .msi para Windows 64-bit).
  2. Ejecutar el instalador. Marcar la opción "Automatically install the necessary tools" si se solicita.
  3. Al finalizar, abrir una nueva ventana de PowerShell o Símbolo del sistema y verificar: 
    node --version
npm --version

[IMAGEN: Instalador de Node.js en Windows mostrando la pantalla de bienvenida con la versión 20.x LTS seleccionada]

[IMAGEN: PowerShell en Windows mostrando la salida de node --version (v20.x.x) y npm --version]

4. Obtener el código fuente

Abrir PowerShell o Git Bash y ejecutar: 

# Clonar el repositorio
git clone <URL_DEL_REPOSITORIO> fundecodes
cd fundecodes\Front\frontfundecodesdigital

La estructura del frontend es la siguiente:

Front/frontfundecodesdigital/
├── src/
│   └── app/                # Rutas y páginas Next.js (App Router)
├── public/                 # Archivos estáticos (íconos, imágenes)
├── next.config.mjs         # Configuración de Next.js
├── tailwind.config.js      # Configuración de Tailwind CSS
├── postcss.config.mjs      # PostCSS
└── package.json            # Dependencias

[IMAGEN: Explorador de archivos de Windows o PowerShell mostrando la estructura de carpetas del proyecto frontend]

5. Configurar variables de entorno

Crear el archivo .env.local en la raíz de la carpeta frontfundecodesdigital: 

# Abrir el Bloc de notas para crear el archivo
notepad .env.local

Agregar el siguiente contenido:

# URL del backend NestJS
NEXT_PUBLIC_API_URL=http://localhost:4000

# (Opcional) Para builds de producción
NEXT_PUBLIC_APP_NAME=Fundecodes Digital

[IMAGEN: Bloc de notas de Windows con el archivo .env.local abierto y las variables configuradas]

6. Instalar dependencias

Desde la carpeta frontfundecodesdigital en PowerShell:

npm install

Este proceso puede tardar entre 1 y 3 minutos dependiendo de la velocidad de la conexión a internet. Al finalizar debe mostrar un mensaje similar a: 

added 312 packages, and audited 313 packages in 45s

[IMAGEN: PowerShell en Windows mostrando la salida de npm install completada exitosamente con el número de paquetes instalados]

7. Iniciar el servidor de desarrollo

npm run dev

La salida esperada es:

  ▲ Next.js 14.x.x
  - Local:        http://localhost:3000
  - Environments: .env.local

 ✓ Starting...
 ✓ Ready in 2.1s

Abrir un navegador web y visitar http://localhost:3000.

[IMAGEN: Terminal PowerShell mostrando la salida de inicio de Next.js con el mensaje "Ready" y el puerto 3000]

[IMAGEN: Navegador web mostrando la página de inicio del sistema Fundecodes Digital en http://localhost:3000]

8. Build de producción (opcional)

Para generar una build optimizada para producción:

# Generar build de producción
npm run build

# Iniciar el servidor de producción
npm run start

El servidor de producción también estará disponible en http://localhost:3000 pero con el código compilado y optimizado.

9. Verificar la conexión con el backend

Para confirmar que el frontend se comunica correctamente con el backend:

  1. Asegurarse de que el backend esté corriendo en http://localhost:4000 (ver KB0001).
  2. Abrir las herramientas de desarrollador del navegador (F12) → pestaña Network.
  3. Navegar a la sección de login del sistema.
  4. Verificar que las peticiones a la API retornen códigos HTTP 200 o 401 (no errores de red como ERR_CONNECTION_REFUSED).

[IMAGEN: DevTools del navegador mostrando la pestaña Network con peticiones exitosas al backend en localhost:4000]

10. Resolución de problemas comunes en Windows

SíntomaCausa probableSolución
npm : El término 'npm' no se reconoce Node.js no está instalado o no está en el PATH Reinstalar Node.js y abrir una nueva ventana de PowerShell
Error de política de ejecución de scripts en PowerShell Windows bloquea scripts por defecto Ejecutar: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
Puerto 3000 en uso Otro proceso ocupa el puerto Ejecutar npm run dev -- -p 3001 para usar otro puerto
Error ERR_CONNECTION_REFUSED al hacer login El backend no está corriendo Iniciar el backend primero (ver KB0001), luego reiniciar el frontend
Páginas en blanco después de login Variable NEXT_PUBLIC_API_URL incorrecta o ausente Verificar el archivo .env.local y reiniciar el servidor
Error de CORS al llamar al backend El backend no permite el origen del frontend Agregar http://localhost:3000 a CORS_ALLOWED_ORIGINS en el .env del backend
